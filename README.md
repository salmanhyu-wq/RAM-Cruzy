# 로컬 램 크루지_EX

Mac의 메뉴 막대에서 통합 메모리, 프로그램별 RAM, 로컬 AI 작업을 함께 봅니다. Stats처럼 메모리 압력과 사용량을 먼저 보여 주고, 모델 관리와 작업 제어를 더했습니다.

## 시작하기 전에

Apple Silicon Mac과 macOS 14 이상이 필요합니다. 빌드는 macOS 27.2 SDK와 Swift 6.4.2에서 확인했습니다. 로컬 AI 서버를 설치하기 전에도 Mac의 램과 스왑을 볼 수 있습니다.

메뉴 막대에서 **설정 → 로컬 서버 연결**을 열어 사용 중인 서버의 포트를 맞춰 주세요. ComfyUI 직접 실행은 `~/Documents/ComfyUI`의 `main.py`와 `.venv/bin/python`을 사용합니다. 회사용 Hermes 프로필을 쓰면 공개판의 기본 위치는 `~/.hermes/office-runtime/profiles`입니다.

**연결 켜기.command**는 Hermes Agent와 기존 Splash 세션 중계기를 함께 사용하는 경우에 실행합니다. 컴퓨터의 램만 보려면 **빌드.command**만 실행하면 됩니다.

## 실행

1. 폴더에서 **빌드.command**를 더블 클릭합니다. Apple 명령줄 개발 도구와 Apple Silicon Mac이 필요합니다.
2. 메뉴 막대의 크루지 아이콘 뒤 원이 초록(여유), 주황(주의), 빨강(부족)으로 바뀝니다. 아이콘을 누르면 전체 화면 앱에서도 아이콘 아래에 빠른 관리가 열립니다. Dock에서도 램 사용률, 최근 1분 추이와 AI 서버·모델을 볼 수 있습니다.
3. **쉬는 AI 비우기**로 한꺼번에 정리하거나 모델 옆 **램에서 내리기**로 하나씩 정리합니다. 답변 중인 작업은 방 제목과 봇 이름을 확인한 뒤 **작업 중단**을 누릅니다. Dock 우클릭에도 일괄 비우기와 자동 켬·끔이 있습니다.
4. 빠른 관리의 제목 줄은 고정되고, 그 아래 램 상태부터 AI 목록까지 함께 스크롤됩니다. 왼쪽 위 칩 아이콘으로 전체 창을 열어 모델과 대화, 저장 파일, 최근 사용, 스왑 기록을 확인합니다. **비울 수 있는 항목 보기**를 누르면 바로 정리할 수 있는 모델과 캐시만 표시됩니다.
5. 빠른 관리의 톱니바퀴나 `⌘,`로 **설정**을 엽니다. 메뉴 막대 색의 뜻을 확인하거나 로컬 서버 포트를 수정하고 **연결 저장**을 누릅니다.

## 앱 언어

**설정 → 앱 언어**에서 **시스템 설정 따르기**, **한국어**, **English**를 선택할 수 있습니다. 기본값은 시스템 설정을 따릅니다. macOS의 선호 언어 목록에서 한국어와 영어 중 먼저 나오는 언어를 사용하고, 둘 다 없으면 영어로 표시합니다. 언어를 바꾼 뒤 메뉴에서 **완전히 종료**를 누르고 앱을 다시 엽니다.

In **Settings → App Language**, choose **Follow System Settings**, **한국어**, or **English**. The default uses your first supported preferred language in macOS and falls back to English. Choose **Quit Completely** and reopen RAM Cruzy to apply a change.

## 로컬 AI 활동 그래프

빠른 관리와 전체 창에서 최근 5분의 AI 서버 램과 작업 구간을 함께 봅니다. 위 그래프의 선은 확인된 AI 서버 램의 합계입니다. 아래의 가는 막대는 대화·그림·영상 작업이 있던 구간을 표시합니다. 소리와 기타 작업은 관측되면 줄이 추가되고, 대기 중인 구간은 점선으로 표시합니다. 마우스를 올리면 그때의 램과 서버·모델·작업 이름을 확인할 수 있습니다.

서버 조회 후 약 3초 간격으로 기록을 모읍니다. 이 앱을 켠 동안의 최근 기록을 표시하며, 관측 공백이나 측정 대상이 달라진 지점에서는 램 선을 이어 그리지 않습니다. 램 수치가 없는 서버는 합계에서 빠지고 작업 구간은 표시됩니다.

## 서버 켜기와 모델 올리기

빠른 관리 왼쪽 위의 칩 옆 **서버 관리** 아이콘에서 서버 상태를 봅니다. 같은 아이콘을 다시 누르면 램 화면으로 돌아갑니다. **켜기·끄기**와 모델 메뉴로 바로 제어할 수 있습니다. 전체 창 **지금 쓰는 램**에도 같은 서버 관리가 있습니다. 진행·대기 작업이 확인되면 서버 종료를 기다립니다.

**저장한 모델**에서 **램에 올리기·내리기**를 누릅니다. Splash에서 다른 모델을 고르면 진행 중인 요청을 확인한 뒤 선택한 모델로 서버를 다시 준비합니다. 준비 실패 시 원래 모델 설정으로 복구를 요청합니다. ComfyUI의 모델과 로라는 워크플로를 실행할 때 함께 올라갑니다.

## 드라이브 검사와 드래그로 추가

**저장한 모델 → 전체 드라이브 검사**로 내장·연결된 로컬 외장 드라이브를 검사합니다. 먼저 서버 보관함을 살피고 나머지 드라이브를 검사하며, 진행 수·발견 수·읽지 못한 위치를 표시합니다. **검사 중지**, **폴더 선택**, 이름·위치 검색과 **로라만** 필터를 사용할 수 있습니다. 검사 결과는 이 Mac에 저장됩니다. 전체 검사에서 클라우드 폴더는 맥 파일 검색 결과를 함께 사용하며, 특정 폴더를 선택하면 그 폴더를 직접 검사합니다. 클라우드에만 있는 파일은 다운로드 필요로 표시합니다.

보관함이나 검색 결과의 모델을 위쪽 서버 아이콘으로 끌어 추가합니다. Finder에서 끌어올 수도 있습니다. **공유 연결**은 한 원본을 여러 서버가 사용하게 하고, **복사해서 추가**는 대상 폴더에 별도 파일을 만듭니다. 추가 위치와 방식을 확인한 뒤 실행합니다. 같은 이름이 있거나 형식이 맞지 않으면 이유를 표시합니다. 공유 연결은 원본 드라이브가 연결되어 있고 파일 위치가 유지되어야 사용할 수 있습니다.

## 자동 비우기

빠른 관리의 일괄 버튼 옆 **자동 비우기**에서 바꿉니다. 처음에는 꺼져 있어요. 켜두면 Mac이 새 스왑 쓰기를 한 구간에서, 쉬고 있다고 다시 확인된 AI 모델과 캐시만 비웁니다. 반복 실행은 최소 2분 간격입니다. 앱 첫 측정이나 측정 공백에는 작동하지 않습니다. 작업 중이거나 대기 중인 모델은 제외됩니다.

## 관제탑

왼쪽 **관제탑**이나 Dock 우클릭의 **관제탑 열기**에서 다섯 서버를 확인합니다. 접수 수, 중계 중인 요청, 램 확보 대기, 재시도와 성공 수를 표시합니다. 수치는 중계기를 시작한 시점부터 집계합니다. 각 서버의 **연결 주소 복사**는 API 클라이언트에 바로 넣을 주소를 복사합니다. ComfyUI는 **작업 화면 열기**로 들어갑니다.

## 비집고 넣기

**설정 → 비집고 넣기**에서 켭니다. 기본은 꺼짐입니다. 이미 Splash 중계기를 연결한 Mac에서 새 기능을 쓰려면 요청이 없을 때 **연결 켜기.command**를 다시 실행합니다. 램크루지가 열려 있는 동안 메모리가 부족해 접수를 기다리거나, 시작하기 전에 받은 메모리 부족 응답을 처리합니다.

| 서버 | 연결 주소와 작업 |
|---|---|
| Splash · Hermes | 기존 8002 개인·봇 연결을 사용합니다. |
| MLX-Serve | `http://127.0.0.1:8002/fit/mlxServe` 뒤에 API 경로를 붙입니다. 채팅과 미디어 생성에 사용합니다. |
| LM Studio | `http://127.0.0.1:8002/fit/lmStudio` 뒤에 API 경로를 붙입니다. 채팅과 모델 불러오기에 사용합니다. |
| MLX Studio | `http://127.0.0.1:8002/fit/mlxStudio` 뒤에 API 경로를 붙입니다. 채팅과 임베딩에 사용합니다. |
| ComfyUI | **관제탑 → 작업 화면 열기**에서 엽니다. 기존 8188 주소를 중계기로 전환한 Mac에서는 저장된 주소와 영상 도구도 그대로 쓸 수 있습니다. 새로 연결하는 Mac에서는 기본 8189입니다. |

관제탑에서 복사한 OpenAI 호환 주소 끝에는 `/v1`이 들어 있습니다. 램크루지의 기존 **로컬 서버 연결**에는 서버의 원래 포트를 사용합니다. 데스크톱 앱 안에서 보내는 요청과 원래 포트에 바로 보내는 요청에는 중계기가 개입하지 않습니다. ComfyUI가 접수 번호를 반환한 작업이나 답변을 시작한 요청은 중복 실행을 막기 위해 다시 보내지 않습니다.

쉬는 상태가 확인된 Splash·MLX-Serve의 모델과 ComfyUI 캐시를 비웁니다. 램이 모자란 서버의 모델, 실행·대기 중인 작업, 작업 상태를 확인할 수 없는 서버는 보호합니다. **자동으로 닫아도 되는 앱 추가**에 직접 등록한 앱이 충분히 오래 쉬었을 때만 정상 종료를 요청합니다. **GPU 상한 한 번 사용 준비**는 Mac 관리자 승인 후 30분 동안 요청 하나에 사용할 준비를 합니다. GPU 부족 응답을 받았고 Mac의 메모리 압력이 정상이며 모델 상태를 확인할 수 있을 때 사용합니다. 작업 자체가 서버 상한을 넘으면 서버의 원래 오류를 표시합니다.

## 램 쥐어짜기

**쉬는 항목 비우기**를 하고도 메모리가 부족하면 **램 쥐어짜기**에서 사용할 모델을 고릅니다. 기본 30분 동안 화면에서 사용하지 않은 일반 앱이 최근에 쓴 순서로 표시됩니다. 이번에만 켜 둘 앱은 체크를 풉니다. 다음에도 보호하려면 앱 옆 **항상 제외**를 누릅니다. **설정 → 항상 제외할 앱**에서 앱을 추가하거나 제외를 해제할 수 있습니다. 생성 서버, 브라우저, 연결 도구, 사용 시간을 아직 모르는 앱은 보호합니다. 앱에는 정상 종료를 요청하며 저장 창이 떠 있는 동안 계속 열려 있을 수 있습니다.

Mac에 남길 메모리는 64GB Mac 기준 기본 8GB입니다. **설정 → 램 쥐어짜기**에서 시간과 메모리 여유를 바꿀 수 있습니다. macOS 관리자 승인 후 이번에만 GPU 메모리 상한을 올립니다. 선택한 모델이 내려가면 기존 상한으로 돌아갑니다. **GPU 상한 원복**으로 먼저 되돌릴 수도 있습니다. 프로그램이 끝나거나 끊기면 보조 도구가 상한을 돌려놓습니다. 모델이 5분 동안 올라오지 않거나 서버 상태를 45초 이상 읽을 수 없을 때도 원복합니다.

모델이 램에서 내려갔는지 확인할 수 있는 Splash, MLX-Serve, LM Studio에서 사용할 수 있습니다. GPU 상한은 Mac 전체에 적용됩니다. 모델 서버에 별도 메모리 제한이 있으면 그 제한은 계속 적용됩니다.

## 모델 보관함과 최근 사용

- **모델 보관함**에서 서버, 용도, 이름으로 모델 파일을 찾아봅니다. 파일 크기는 모델 파일 길이를 합친 값입니다. 저장 위치는 현재 Mac의 Splash 로컬 모델, MLX-Serve, LM Studio, MLX Studio 기본 모델 폴더와 ComfyUI 모델 폴더입니다.
- **휴지통**은 확인한 항목 하나를 macOS 휴지통으로 옮깁니다. Splash 자동 시작·현재 선택 모델, 외부 파일 링크, 실행 중인 다른 서버의 모델은 앱에서 휴지통으로 옮길 수 없습니다. 대신 Finder에서 위치를 확인할 수 있습니다.
- **최근 사용**은 30일 동안 MLX-Serve의 날짜별 통계와 Hermes의 Splash 호출 통계를 읽습니다. 기간 경계에 걸친 Hermes 세션은 마지막 사용 날짜만 표시합니다. 다른 모델은 이 앱이 실행된 동안 확인한 활동을 표시합니다. 목록에 기록이 없다는 것만으로 미사용을 확정할 수 없습니다.

## 스왑 진단

현재 스왑 크기, 앱 실행 중에 관찰한 읽기·쓰기 환산량, 지난 7일의 쓰기 추이를 봅니다. 1MB 이상 바뀐 시점에는 함께 관찰된 AI 작업, 사용량이 큰 프로그램과 RAM이 늘어난 프로그램이 표시됩니다. 다른 앱을 원인으로 판정하지 않으며, 앱이 꺼져 있거나 Mac이 잠든 구간의 작업은 확인할 수 없습니다. 모델 및 스왑 관찰 기록은 이 Mac에 30일 동안 저장됩니다.

**유휴 램 회수**는 작업 없음이 확인된 엔진의 모델이나 캐시만 요청합니다. 작업 중·대기 중·상태 미확인 항목을 건너뜁니다. 회수 버튼을 누르면 서버가 작업 상태를 다시 확인합니다. 프로그램 목록의 **종료**는 macOS 정상 종료를 요청합니다. 프로그램은 저장 여부를 물을 수 있습니다.

## Splash에서 봇과 세션 보기

이 Mac의 Splash 중계기 기본 주소는 8002입니다. 앱은 기존 중계기에서 모델 RAM과 개인·봇 슬롯 개수를 읽습니다.

- **연결 켜기.command**는 기존 Splash 중계기 런치 설정을 백업하고, 작업이 없을 때만 이 프로젝트의 중계기로 전환합니다. Splash 엔진과 모델은 재시작하지 않습니다.
- 이 Mac의 Splash 로컬 경로를 사용하는 Hermes 프로필에 요청 이름 표시 확장을 추가합니다. 현재 열린 Hermes 작업이 끝난 뒤 앱을 다시 열면 적용됩니다.
- 확장이 적용된 뒤 **개인 1 · 봇 1~3** 각 칸에 대화 제목 앞부분, 봇·세션·모델이 표시됩니다. 제목을 찾을 때는 현재 프로필의 Hermes 세션에서 제목만 읽습니다. 다른 앱의 연결에는 식별자가 없을 수 있습니다. 슬롯 중단은 그 요청 연결만 닫습니다. 공유 모델 RAM은 모델을 내릴 때 회수합니다.
- 이 Mac에서 모델이 내려가고 대화 캐시만 남으면 **대화 캐시 내리기**로 Splash 엔진을 잠시 쉬게 할 수 있습니다. 다음 요청은 중계기가 엔진을 켤 때까지 기다립니다. 진행·대기 중인 Splash 요청이나 연결된 ComfyUI 작업이 있으면 내리기를 건너뜁니다. 이 버튼은 직접 누를 때 작동합니다.
- **연결 끄기.command**는 기존 중계기를 복원하고 이 확장 설정을 지웁니다. 코딩 폴더는 연결을 끄기 전까지 유지해 주세요.

## 서버별 기능

| 서버 | 표시 | 제어 |
|---|---|---|
| Splash | 엔진 RAM, 모델 상태, 공유 슬롯 | 유휴 모델 내리기. 확장 연결 후 선택한 요청 중단 또는 대기 취소 |
| MLX-Serve | 올라온 모델, 포트, 서버가 보고하는 RAM과 작업 수 | 모델별 내리기. 실행·대기 수가 모두 0일 때 일괄 후보 |
| LM Studio | RAM에 올라온 모델 인스턴스 | 모델별 내리기. 작업 상태가 미확인이므로 일괄 제외 |
| MLX Studio | 게이트웨이의 모델 목록 | 앱에서 모델 종료 |
| ComfyUI | 진행·대기 작업, 워크플로에 명시된 이미지·영상 모델 | 작업별 중단 또는 취소. 대기열이 비었을 때 캐시 비우기 또는 확인된 로컬 서버 종료 |

음성, 영상, 이미지 생성 앱도 전체 프로그램 목록에 나타납니다. 서버가 작업명이나 RAM 수치를 공개하지 않으면 앱은 그 값을 추정하지 않습니다. ComfyUI에서 오래된 버전을 쓰는 경우 실행 작업의 개별 중단은 해당 버전이 `prompt_id`를 지원해야 합니다. 스크립트는 기본 포트의 인증 없는 로컬 서버에 맞춰져 있습니다.

- Hermes와 함께 설치된 Python으로 `-B 검증/splash_gate_check.py`를 실행하면 별도 포트에서 개인 1개와 봇 3개를 띄워 선택한 슬롯만 중단하는 동작을 시험합니다.
